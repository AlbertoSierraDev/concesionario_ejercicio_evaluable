# Vértice Motor

**Concesionario ficticio de BMW · Proyecto de Lenguajes de Marcas · 1.º de ASIR**

![BMW en una carretera de montaña al atardecer, fotografía de portada de Vértice Motor](img/portada.webp)

Vértice Motor es una web de tres páginas para presentar un concesionario, comparar seis BMW y simular una solicitud de prueba de conducción. Está hecha con **HTML5 y CSS** y se puede abrir en el navegador directamente desde la carpeta del proyecto.

## Páginas

| Página | Contenido | Hoja de estilos |
| --- | --- | --- |
| [Inicio](index.html) | Portada, presentación del concesionario, tres vehículos destacados y servicios. | [index.css](css/index.css) |
| [Vehículos e información](informacion.html) | Seis fichas con motor, potencia, combustible y precio orientativo, además de una tabla comparativa y fotos de las instalaciones. | [informacion.css](css/informacion.css) |
| [Contacto](contacto.html) | Datos ficticios y un formulario para consultar un modelo o proponer una fecha de prueba. | [contacto.css](css/contacto.css) |

## Cómo abrirlo

Descarga el repositorio como ZIP desde **Code → Download ZIP**, extráelo y abre `index.html`. Mantén las carpetas `css/` e `img/` junto a las páginas. Puedes navegar por el sitio sin conexión, sin instalar paquetes y sin iniciar un servidor.

```text
.
├── README.md
├── index.html
├── informacion.html
├── contacto.html
├── css/
│   ├── index.css
│   ├── informacion.css
│   └── contacto.css
└── img/
    ├── logo.svg
    └── fotografías en WebP
```
